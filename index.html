Gundam Assemble Map Builder

Paint elevation and ground onto any hex field, then export a PDF.

Field

Resizing keeps terrain on any hex label that still exists.

Brush

Click or drag across hexes to paint. Keys 0–4 set elevation. Only ticked layers are painted or erased. Choosing a feature switches the brush to features only; choosing an elevation or ground type switches features off.

Upgrades

Place Upgrade tokens with the brush, then distribute. Every Upgrade token and any Shield, Speed or Strength Upgrade already on the map is shared out equally. Distribute again to reshuffle.
